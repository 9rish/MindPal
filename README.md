# PetCare Dashboard  

A gamified mental health dashboard that combines **self-reflection, therapy support, and virtual pet interaction** to make wellness engaging.  

---

## 🐾 Overview  
The **PetCare Dashboard** lets users interact with a customizable pet (Cat, Dog, Penguin, or Rabbit) whose animations reflect the user’s mood (powered by sentiment analysis).  
The platform combines **journaling, quests, games, and therapy tools** to encourage daily mental health care.  

---

## ✨ Features  

### 1. Tracking  

**Journal Entry**  
- Users can type or speak about daily experiences.  
- AI-powered sentiment analysis assigns a mood with confidence score.  
- Pet animations update in real-time to reflect emotions.  

**Quests**  
- Daily, weekly, and monthly wellness tasks.  
- Examples:  
  - *Mindful Moments* – 5 minutes of reflection.  
  - *Gratitude Practice* – Write 3 things you’re grateful for.  
- Completing quests rewards **coins**.  

---

### 2. Pets  

**Customization**  
- Buy hats, outfits, accessories, and backgrounds for pets.  

**Play**  
- Mini-games designed for relaxation and fun:  
  - *Puzzle Game* (Candy Crush style).  
  - *Trainer Duel* – obstacle race with pets.  
  - Other casual games.  

**Food**  
- Buy and feed your pet to keep it energized and happy.  

---

### 3. Explore  

**Leaderboard**  
- Ranks users by XP and completed activities.  

**Premium Features**  
- Unlock enhanced pet care, advanced play, and exclusive therapy tools.  

**Therapy Section**  
- Browse and connect with professional therapists.  
- Detailed therapist descriptions.  
- Secure chat requests and sessions.  

**Mood Analytics**  
- View your complete mood history.  
- Interactive graphs and personalized improvement tips.  

---

## ⚡ Getting Started  

### Prerequisites  
- [Node.js](https://nodejs.org/) (LTS version recommended)  
- npm (comes bundled with Node.js)  

### Installation & Run  
```bash
# Clone the repository
git clone https://github.com/your-username/petcare-dashboard.git

# Navigate into the project folder
cd petcare-dashboard

# Install dependencies
npm install

# Start development server
npm run dev
