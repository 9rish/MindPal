# MindPal
MindPal — your AI-powered Talking Tom for mental wellness. Designed for teens, college students, and young adults, it turns mood tracking and mental health into a fun, interactive, and stress-free experience

TO run the code in terminal type : `npm run dev`

This Branch focuses on helping users connect to certified therapists by verifying their RCC number. The users can Schedule sessions with the therapists and get the expert's opinion. This will overalll guide them to a much more positive direction.

 The therapists also log into the same Webpage using their login Credentials that are provided to them on registering. They can extract the user's journals once the user requestes for session with them. They can also access the sentiment analysis performed by the AI on their journal entries.
